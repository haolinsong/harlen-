# Python 学习路线

本路线参考 Python-100-Days 的主题划分，并按“小 Demo -> 小项目 -> 综合项目”组织。

## 阶段一：Day01-20 Python 语言基础

当前已经实现。内容覆盖环境、变量、运算符、分支、循环、常用数据结构、函数、装饰器、
递归和面向对象编程。

验收目标：能够独立阅读和编写几百行以内的命令行程序，并能把重复逻辑拆成函数和类。

## 阶段二：Day21-30 Python 语言应用

计划内容：

- 文本、二进制文件和上下文管理器。
- 异常处理与自定义异常。
- JSON、CSV、Excel、Word、PowerPoint 和 PDF。
- Pillow 图像处理。
- 邮件、短信和正则表达式。

验收项目：批量读取 CSV，生成统计结果、Excel 报表和邮件附件。

## 阶段三：Day31-45 进阶语法、Linux 与数据库

计划内容：

- 迭代器、生成器、并发编程和常用算法。
- Linux 命令、文件系统、进程和环境变量。
- MySQL、SQL、索引、事务以及 Python 数据库访问。

验收项目：从数据库读取业务数据，完成清洗和导出，并能解释事务提交与回滚。

## 阶段四：Day46-65 Web 开发

计划内容：

- HTTP、Django、模板、ORM、Cookie、Session 和中间件。
- REST API、JWT、缓存、异步任务、单元测试与部署。
- FastAPI 或 Flask 作为轻量 API 框架补充。

验收项目：实现带登录、数据库和 REST API 的任务管理服务。

## 阶段五：Day66-80 数据分析

计划内容：

- NumPy、Pandas 和数据清洗。
- Matplotlib、Seaborn 和可视化。
- 描述统计、概率分布和假设检验。

验收项目：完成一份包含数据清洗、指标计算和图表的分析报告。

## 阶段六：Day81-90 机器学习

计划内容：

- Scikit-learn 工作流。
- 特征工程、训练集与测试集。
- 回归、分类、聚类和模型评估。

验收项目：训练一个可重复评估的模型，并解释数据泄漏与过拟合。

## 阶段七：Day91-100 综合实践

计划内容：

- 自动化测试、日志、配置和工程化。
- API、数据库、数据分析或机器学习的综合项目。
- README、部署说明和问题复盘。

验收目标：独立完成一个能安装、运行、测试和演示的 Python 项目。
