# 来源摄入

执行根目录 [AGENTS.md](../../../AGENTS.md) 的 Schema；其中的权限、对齐、并发写入和记账要求适用于整个流程。本 Skill 只展开摄入步骤。

1. 读取来源全文；有图片时先读文本，再单独查看相关图片。先读 wiki/index.md 定位已有知识，回看 wiki/QUESTIONS.md。新建页面前执行根规则的名称与主题对齐。
2. 汇报 3–7 条要点及最有价值之处，与 Harlan 确认重点和取舍。若已明确重点，或明确要求批量、少监督地摄入，按已有授权继续。
3. 外部来源写入或更新 wiki/sources/ 摘要：出处、核心论点、关键细节、局限。同一资料复用原页；对话或网页来源保留原始 URL、作者、访问日期等可核实信息，不编造 raw 路径，也不替 Harlan 写入 raw/。
4. 将结论并入已有概念/实体页并追加来源；未命中才新建并补齐 aliases。实体建页门槛、冲突标注遵循根规则。
5. 有可复用命令、配置或步骤时同步更新 howto，给出验证方法。只把实际验证通过的日期填入 verified；未验证填空并说明验证边界。
6. 只有“整理到笔记中”“整理成复习笔记”“存成笔记”等明确复习要求才额外更新 outputs/ 的稳定主题页。仅说“整理”时执行普通摄入，产出 wiki。新建页或重排复习正文时读取 [页面骨架](references/page-templates.md)，无需为小修重读模板。
7. 来源改变全局判断时更新 overview；主题文件完成后，按根规则重读共享文件，再更新 index 并追加 ingest 日志。若资料回答开放问题，主动提示 Harlan；确认后读取 [问答 Skill](../harlan-wiki-query/SKILL.md)，落盘答案并将问题移入“已解决”，注明结论页面。
8. 审阅 diff、运行 lint，回报结论和新增/修改文件。

## 个人记录

raw/personal/ 不走客观摘要页流程：提炼进概念/howto，并标“个人经验”；个人记录不计入 confidence 的来源数量。引用外部资料时关联已有来源；找不到时明确提醒“这条结论目前没有外部依据”。

## 输入工具按需加载

- 普通公开网页：读取 [defuddle](../defuddle/SKILL.md)，先清洗正文，再核对代码、表格、图片说明是否缺失；失败或内容不全时用可用网页/浏览器工具补足。Markdown 原文直接读；登录页、动态页面不用清洗结果代替完整来源。
- PDF：使用当前环境已有 PDF Skill，不重复安装。
- Obsidian 特殊语法不确定时读取 [obsidian-markdown](../obsidian-markdown/SKILL.md) 及所需参考。字段、命名和权限始终以根 Schema 为准。
