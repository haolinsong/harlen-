# 页面骨架

本文件仅展开 AGENTS.md 授权的正文模板；字段、命名、来源置信度等 Schema 均以根文件为准。保留已有主题的合适结构，不为模板而覆盖内容。

## concept

首行用一句话定义，然后依次写“核心要点”“与相邻概念的区别”；版本或平台敏感时增加“前提与适用范围”；以“相关”收尾。

## howto

首行说明解决的问题。正文使用“适用环境”（版本敏感时必填）、“目标”“步骤”“验证”“已知坑”“相关”。每条命令说明用途；验证不可省略，静态核对不等于实际运行成功。

## source / entity

来源摘要记录出处、核心论点、关键细节和局限。实体页说明对象身份、职责与相关概念，满足根 Schema 的建页门槛后才创建，避免薄页。

## 主题复习页

“整理到笔记”生成的复习页至少覆盖以下内容，可按主题扩展；普通 Query 按问题选用恰当结构，不强行补齐无关章节。

```markdown
## 一句话结论
最值得记住的结论。

## 核心要点
3–7 条独立可读的要点。

## 怎么用
适用场景、组合方式；有命令就给出可复制命令。

## 相关
关联概念、操作、来源页面，并说明阅读价值。
```

wiki 保存细粒度原理与出处，outputs 讲清楚学习主题；用链接连接，避免长篇重复。所有流程图遵循根 Schema 的 Mermaid 与图后解释要求。
