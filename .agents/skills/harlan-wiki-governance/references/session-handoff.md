# 新主题会话交接

当 Harlan 表示要为新学习主题单独开会话，主动给一段可复制的启动提示词。只补充主题、范围、与其他会话的边界和首次任务，不复制 AGENTS.md 全文。

提醒从本地项目“Harlan的第二大脑”创建会话，以便发现项目规则与 Skill。空白会话须收到第一条消息才能工作；新会话不继承当前对话历史，交接信息必须已经落盘。

按当前主题填写以下模板，不执行模板中的学习任务：

```text
请接手本项目的【主题】学习。
遵守根目录 AGENTS.md，并按其中路由按需读取项目 Skill。
先读 wiki/index.md、wiki/QUESTIONS.md 和 wiki/log.md 最近记录，
检查 Git 状态、记录规则哈希，并搜索已有页面的文件名、title、
aliases 和正文标题防止重复。
本会话只负责【主题范围】，不改其他主题或库级规则。
首轮只读初始化，简要说明已有内容与缺口，然后等待我的具体问题。
```

如 Harlan 已在当前请求指定首个具体学习任务，用该任务替换最后一句；尊重已给出的范围和授权。
