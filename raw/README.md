# raw/ — 原始资料层

这里存放**未经加工的原始资料**：文章剪藏、论文 PDF、播客转录、书籍章节、数据文件、截图等。

## 目录分工

| 目录 | 放什么 |
| --- | --- |
| `raw/`（根） | 外部来源：文章剪藏、下载的文档、报错日志原文、官方文档摘录 |
| `raw/assets/` | 图片、截图等附件（Obsidian 附件目录已指向此处） |
| `raw/personal/` | **你自己写的**：排障记录、学习笔记、方案设计、踩坑总结 |

分开放的原因：两者走**不同的摄入流程**。外部来源是"提炼事实"，你自己的记录是"确立立场"——后者不会计入置信度的来源数量，避免用自己的文章给自己背书。

规则：

1. **不可变。** Agent 只读取，不修改、不重命名、不删除这里的任何内容。
2. 这是全库的**事实来源**。wiki 中的论断若与 raw 冲突，以 raw 为准，并回头修正 wiki。
3. 文件名尽量带日期或来源，例如 `2026-09-13 某某文章.md`；网页剪藏推荐用 Obsidian Web Clipper。
4. 图片等附件统一放 `raw/assets/`（Obsidian 设置 → 文件与链接 → 附件默认位置，已配置好）。
5. 若确需改动源文件（例如清理格式），先复制一份再改，保留原始版本。
6. 报错日志、`docker inspect` 输出、配置文件这类"证据",原样粘贴进文件即可，**不要整理**——整理是摄入时要做的事，原始形态同样有保留价值。

摄入流程见根目录 `AGENTS.md` 的 §4。
