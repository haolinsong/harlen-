# 英语发音学习笔记

这是一份持续扩展的英语发音专题笔记，用于集中整理发音规则，并把连读内容统一记录成“连读组合、中文意思、连读音标、练习例句”。规则用于帮助预测，遇到新词仍应通过学习词典的 IPA 确认。

## 1. 规则动词 `-ed` 的三种读音

### 一句话结论

判断规则动词 `-ed` 的发音时，要听动词原形的最后一个**音**：`/t/` 或 `/d/` 后读 `/ɪd/`，其他清辅音后读 `/t/`，元音或其他浊辅音后读 `/d/`。

### 完整对照

| 原形最后一个音       | `-ed` 读音                | 常见音素                                        | 例词                                                                                  |
| ------------- | ----------------------- | ------------------------------------------- | ----------------------------------------------------------------------------------- |
| `/t/` 或 `/d/` | `/ɪd/`；部分口音或语流接近 `/əd/` | `/t, d/`                                    | `wanted /ˈwɒntɪd/`、`needed /ˈniːdɪd/`、`started /ˈstɑːtɪd/`                          |
| 其他清辅音         | `/t/`                   | `/p, k, f, θ, s, ʃ, tʃ/`                    | `helped /helpt/`、`looked /lʊkt/`、`laughed /læft/`、`washed /wɒʃt/`、`watched /wɒtʃt/` |
| 元音或其他浊辅音      | `/d/`                   | 元音及 `/b, g, v, ð, z, ʒ, dʒ, m, n, ŋ, l, r/` | `played /pleɪd/`、`loved /lʌvd/`、`cleaned /kliːnd/`、`called /kɔːld/`                 |

最容易执行的判断顺序是：

1. 最后一个音是 `/t/` 或 `/d/`：读 `/ɪd/`。
2. 否则，如果最后一个音是清辅音：读 `/t/`。
3. 其余情况，也就是元音或浊辅音之后：读 `/d/`。

> [!tip] 最短口诀
> `/t, d/` 后加一个音节读 `/ɪd/`；其他音先判断声带，清音配 `/t/`，浊音和元音配 `/d/`。
