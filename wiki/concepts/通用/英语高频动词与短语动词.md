# 英语高频动词与短语动词

高频动词通过宾语、补语、介词和小品词扩展出大量意义；学习时应同时掌握“核心动作感觉、句型结构和完整搭配”。

> [!info] 个人经验
> 原始笔记用 `up/down/off/out` 的空间方向串联短语动词。这是有效的记忆入口，但短语动词经常词汇化，实际意义不一定能由各部分直接推导。

## 核心要点

### 五个高频核心动词

- `get`：获得、到达、变成；常见结构有 `get + 形容词`、`get sb to do`、`get sth done`。
- `make`：制作或造成；`make + 宾语 + 形容词` 表示使某人进入状态，`make sb do` 不带 `to`。
- `have`：拥有、经历、吃喝；`have sb do` 表示安排某人做事，`have sth done` 表示让某事被处理。
- `take`：把事物带走或承担到自己这一侧，因此可扩展为拿、乘坐、花费、经历和承担。
- `go`：移动或状态变化；`go shopping` 表示去参加活动，`go wrong/bad` 表示进入某种状态。

### 小品词提供方向线索

| 小品词 | 常见联想 | 示例 |
| --- | --- | --- |
| `up` | 向上、增强、完成 | `turn up`、`eat up`、`cheer up` |
| `down` | 向下、降低、记录 | `slow down`、`cut down`、`write down` |
| `off` | 分离、停止、离开 | `take off`、`turn off`、`cut off` |
| `out` | 向外、显现、耗尽 | `point out`、`come out`、`run out` |
| `away` | 远离、移走 | `run away`、`give away` |
| `over` | 越过、结束、复查 | `get over`、`take over`、`look over` |

这些联想不能代替完整词义。例如 `give up` 是“放弃”，不能只从“向上”推出；应把 `give up` 作为一个词汇单位记忆。

### 三类多词动词

1. **短语动词**：动词 + 小品词，如 `look up`、`take off`。部分结构的名词宾语可放在中间，但代词通常必须放中间：`look it up`。
2. **介词动词**：动词 + 介词，如 `look after`、`depend on`。介词后必须有宾语，不能拆开。
3. **短语介词动词**：动词 + 小品词 + 介词，如 `look forward to`、`put up with`。后面的组成部分通常不能拆开。

## 与相邻概念的区别

- `look` 是主动把视线转向，`see` 是看到，`watch` 是持续观看，`view` 更正式。
- `say` 后接所说内容，`tell` 常接人再接内容，`talk/speak` 强调交谈或说话行为。
- `get sb to do` 带 `to`，`make sb do` 和 `have sb do` 不带 `to`；`get/have sth done` 都可以表示让别人处理某事。

## 前提与适用范围

短语动词常见于口语和中性文体，但不等于“不正式”。及物性、能否拆分以及语体差异应查学习词典，不能只靠空间联想判断。
