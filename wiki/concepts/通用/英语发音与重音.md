# 英语发音与重音

英语拼写可以帮助猜测读音，但字母组合和重音大多是**常见规律而非无例外规则**；新词最终应以带音标和真人录音的学习词典为准。

> [!info] 个人经验
> 原始笔记用字母组合、前后缀和口诀记忆发音。这种方法适合建立第一印象，但把“通常”记成“一定”会产生系统性误读，因此本页只保留可作为预测线索的部分。

## 核心要点

### 拼写只能用于预测

Vowel team 是多个字母共同表示一个元音音素的拼写模式。相邻元音不一定组成 vowel team，例如 `toe /təʊ/` 中的 `oe` 共同发音，`poet /ˈpəʊ.ɪt/` 中的元音分属两个音节。

| 组合 | 主要读音 | 必须同时掌握的变化 |
| --- | --- | --- |
| `ai/ay` | 常读 /eɪ/：`rain/day` | `said /e/`、`plaid /æ/`、`quay /iː/` |
| `ee/ea` | 常读 /iː/：`see/team` | `ea` 还常读 /e/ 或 /eɪ/：`head/great` |
| `ie` | /iː/ 或 /aɪ/：`field/pie` | `friend /e/`、`sieve /ɪ/` |
| `oa/oe` | 常读 /əʊ/，美式 /oʊ/：`boat/toe` | `broad`、`shoe`、`does` 是高频例外 |
| `oi/oy` | 常读 /ɔɪ/：`coin/boy` | 在常用词中相对稳定 |
| `ou/ow` | /aʊ/：`out/cow` | `ou` 变化很多；`ow` 也常读 /əʊ/：`snow` |
| `oo` | /uː/ 或 /ʊ/：`food/book` | `blood/flood` 读 /ʌ/ |
| `ue/ui` | 可读 /uː/：`blue/fruit` | `guest/build/guide` 等不能套用这一读音 |

`ei/ey` 不适合合并成一个固定规则：`vein/they` 读 /eɪ/，`receive/key` 读 /iː/，`height` 读 /aɪ/，`money` 的词尾读 /i/。

`qu` 不是元音组合，常读 /kw/，如 `quick/question`；`unique/antique` 中常读 /k/。

### 重音是倾向，不是公式

- 词典用 `ˈ` 标记主重音、`ˌ` 标记次重音；重读音节通常更长、更响，元音也更清楚。
- 双音节名词和形容词**常常**重读第一音节，双音节动词**常常**重读第二音节，但存在大量例外。
- 同形的名词与动词有时靠重音区分，如名词 `CONtract` 与动词 `conTRACT`。
- 三音节及以上单词没有“统一重读倒数第三音节”的通则。后缀可能影响重音，例如 `-tion/-sion` 前一个音节常重读；`-ic` 前一个音节常重读。
- 同一词族的重音可能移动：`PHOtograph`、`phoTOgrapher`、`photoGRAPHic`。
- 非重读音节常出现弱读元音 /ə/ 或 /ɪ/，具体读音会受单词、词源和口音影响。

### 新词判断顺序

1. 划分音节，确认相邻元音是否共同发一个音。
2. 找出 vowel team，先尝试它最常见的读音。
3. 对 `ow/oo/ie/ou` 等多读音组合尝试第二种高频读音。
4. 结合词义和语境排除同形异音词，如 `bow /bəʊ/` 与 `bow /baʊ/`。
5. 用学习词典确认 IPA、主重音和真人录音，再记录一个例句。

### 常见不发音字母

| 拼写位置 | 常见现象 | 例词 |
| --- | --- | --- |
| 词首 `kn-` | `k` 通常不发音 | `knee`、`knock` |
| 词首 `wr-` | `w` 通常不发音 | `write`、`wrong` |
| 词尾 `-mb` | `b` 通常不发音 | `comb`、`bomb` |
| `-mn` 词尾 | `n` 常不发音 | `autumn`、`column` |
| `bt` | `b` 常不发音 | `debt`、`doubt` |
| `wh-` | 多数词读 /w/；`who/whole` 等读 /h/ | `when`、`who` |

## 与相邻概念的区别

- **拼读规律**解决“看到拼写时如何合理猜测”；**音标**记录词典给出的实际读音。
- **单词重音**强调一个词中的音节；**句子重音**强调一句话里的信息焦点。
- **弱读**不是“含糊地念错”，而是非重读音节在自然语流中的正常变化。

## 前提与适用范围

本页同时出现英式和美式音标差异，例如英式 `/əʊ/` 与美式 `/oʊ/`。学习时可以选择一种口音作为输出目标，但应能识别另一种常见读法。

外部核查参考：[UFLI：Vowel teams](https://ufli.education.ufl.edu/foundations/toolbox-aus/84-88/)、[UFLI：Scope and Sequence](https://ufli.education.ufl.edu/wp-content/uploads/2022/01/UFLI-Scope-and-Sequence-5-21-2.pdf)、[Reading Rockets：Phonics in Practice](https://www.readingrockets.org/reading-101/reading-101-learning-modules/course-modules/phonics/practice)、[British Council：Word stress](https://www.teachingenglish.org.uk/professional-development/teachers/teaching-knowledge-database/t-w/word-stress)。这些资料把基础映射、多读音组合和低频替代拼写分开教学，并把重音描述为规律或倾向，而不是无例外公式。
