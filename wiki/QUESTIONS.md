# 开放问题

把"我想搞清楚 X"记在这里，**不要留在脑子里，也不要留在聊天记录里**。它的作用有两个：给后续摄入一个方向；以及在摄入新来源时，让 Agent 检查这份来源是否恰好回答了某个问题。

## 使用方式

- **登记**：对 Agent 说「我想搞清楚……」或「add question」，它会规范化问题后追加到「待解决」，格式为 `- [ ] 问题内容（opened YYYY-MM-DD）`。
- **闭环**：摄入来源时，Agent 会检查本次来源能否回答列表里的问题；能答就提示你，确认后执行 Query，把结论落盘到 `outputs/`，并把问题从「待解决」移到「已解决」并标注结论文件。
- **归档**：已解决的问题不删除，保留在「已解决」，这样能看到自己的问题是怎么被回答的。

> [!info] 为什么需要这个文件
> 摄入来源最容易退化成"被动地多读一篇"。有了问题队列，每次摄入都变成**在回答一个已经存在的问题**——这是从三份来源里提炼出的最便宜、收益最高的一条实践。
